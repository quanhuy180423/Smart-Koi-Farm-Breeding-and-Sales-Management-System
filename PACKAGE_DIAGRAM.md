## 📦 Package Details Summary

| Package        | Description                         | Dependencies             |
| -------------- | ----------------------------------- | ------------------------ |
| **app**        | Next.js pages và routes             | components, hooks, store |
| **components** | React UI components                 | lib/utils, hooks         |
| **hooks**      | Custom React hooks (TanStack Query) | lib/api, store           |
| **store**      | Zustand state management            | lib/api                  |
| **lib/api**    | API client và services              | axios                    |
| **lib/utils**  | Utility functions                   | -                        |
| **types**      | TypeScript type definitions         | -                        |
| **assets**     | Static files (images, fonts)        | -                        |
| **middleware** | Next.js middleware (auth)           | lib/api                  |

## 🏗️ Technology Stack

| Layer                | Technology                   |
| -------------------- | ---------------------------- |
| **Framework**        | Next.js 15 (App Router)      |
| **UI Library**       | shadcn/ui + Tailwind CSS     |
| **State Management** | Zustand                      |
| **Data Fetching**    | TanStack Query (React Query) |
| **HTTP Client**      | Axios                        |
| **Form Handling**    | React Hook Form + Zod        |
| **Type Safety**      | TypeScript                   |

---

## 📝 Notes

- Sử dụng **Route Groups** `(auth)`, `(home)`, `(customer)`, `(manager)`, `(sale)` để tổ chức routes
- **Hooks** đóng vai trò bridge giữa UI và API services
- **Store** sử dụng Zustand với persist middleware
- **API Services** được tổ chức theo domain (Order, KoiFish, Pond, etc.)
